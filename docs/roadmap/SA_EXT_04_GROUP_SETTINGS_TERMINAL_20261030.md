## Реалізація та інтеграція
- Існуючий користувацький екран домашньої групи тепер дозволяє власнику змінити назву, опис, громаду/церкву, країну, місто, публічність та режим відображення списку учасників.
- Існуючий API `POST /api/groups?action=settings` використовує одне умовне SQL `UPDATE` з перевіркою власника, членства і повного попереднього знімка; конкурентні та неавторизовані зміни не перезаписують чужі значення.
- Перед відкриттям приватної групи є явне підтвердження; згоди окремих учасників на показ імен залишаються чинними, приватні рефлексії доступні тільки учасникам.
- Значення не обрізаються мовчки. Неуспішне або непідтверджене збереження не скидає чернетку. Після успішного readback фокус повертається до розділу налаштувань. Відкладені відповіді не перемальовують сторінку іншого акаунта.
- Канонічна інтеграція: `app/api/groups/route.ts`, `public/app.js`, `public/workspace.js`. Паралельного API, другого джерела даних або нової міграції не створено.
