# SA-EXT-01 — edition provenance and outstanding checks

The public about page uses the same catalog as the reader to list the four locally configured editions, including the Ohiienko entry, its stated source, license, attribution and conversion note. Khomenko and Turkoniak remain external-reader links. Catalog text is escaped and only HTTPS links are rendered. Missing catalog metadata is displayed as unavailable instead of being replaced with a guessed license.

Evidence relevant to the Ohiienko source chain:

- [Wikimedia Commons: 1988 scan](https://commons.wikimedia.org/wiki/File:Ivan_Ohienko_Bible.djvu) describes CC BY-SA 4.0 and a confirmed Wikimedia VRT permission record.
- [Wikimedia Ukraine's 2013 annual report](https://upload.wikimedia.org/wikipedia/commons/0/0d/WMUA-AnnualReport-2013.pdf) records permission from the Ukrainian Bible Society for pre-1991 editions and describes CC BY-SA 3.0.
- The project catalog names [only.bible's Ohiienko repository](https://github.com/onlydotbible/ohienko) as the immediate source and describes conversion to JSON.

These records are useful evidence, not a completed rights audit. The exact only.bible revision used for each local JSON book, its correspondence to the licensed source, all required attribution and ShareAlike terms, and the distinction between the recorded 3.0 and 4.0 descriptions still need independent verification. A citation to a file on Wikimedia is not proof of every redistributed local byte. Browser and physical NVDA acceptance are also outstanding; no release is implied.
