# Scripture Archive R06 DEV1 repair

Readable Windows/WebView2 platform foundation. Core/domain contracts do not depend on pywebview; desktop bridge is one JSON-safe adapter. The frontend is semantic HTML and exposes player, authoring and keymap surfaces. `INSTALL_WINDOWS.bat` + `START_WINDOWS.bat` provide a no-admin developer launch path when Python 3 is installed; `packaging/build_windows.ps1` builds a PyInstaller Windows artifact on a Windows runner.

This lane does not claim independent NVDA acceptance or a Windows `.exe` build when no Windows runner actually executed.
