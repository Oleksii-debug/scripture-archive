# SA-EXT-02 — attempt recovery and private history

An accepted last answer is retained even if the subsequent result calculation or save fails. A signed-in user can resume a result awaiting completion from their private attempt history, including on another device. A guest can resume the attempt while its link or browser session remains available.

Finalization validates the stored answer set and commits progress, any authorized group session, and completion together. Retrying is safe: a deterministic session ID and conditional writes avoid duplicate group records. A recovered older attempt does not replace progress from a newer completed attempt for the same passage. If the group or facilitator membership no longer exists, personal completion still succeeds and the user is told the group result was not saved. Expired attempts cannot accept a late answer, and stale invalidation cannot overwrite a completed attempt.

The progress screen shows up to 100 completed attempts with scores and links to review results or re-read passages after mistakes, plus up to 20 unfinished finalizations. The private reading-data export includes completed attempt history; unfinished attempts and unrelated account data remain outside that export's stated scope. Account deletion already removes the user's attempts and answer records. History is hidden in the interface/API while an attempt is active; this is a memory exercise, not secure proctoring: a user can retain previously disclosed results, Bible text, or exports outside the application.

Tests exercise a real transpiled handler against SQLite, including rollback after partial writes, concurrent finalizers, lost responses, corrupt/missing answers, stale invalidation, expiry, revoked group membership, cross-account access and safe markup. The local Worker/D1 scenario checks actual HTTP completion, retries, history isolation, export and group reporting. Browser, keyboard and physical NVDA acceptance remain unverified. This is one slice of SA-EXT-02, not the full planned mission catalogue, spaced repetition or difficulty system.
