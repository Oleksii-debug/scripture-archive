# Архів Писання — textual-variant transparency policy v1.0

**Status:** canonical pre-production policy  
**Scope:** authored content and answer validation only  
**Date:** 2026-08-17

## Purpose

The project must distinguish theological disagreement from textual-transmission variation. A known manuscript/textual variant is not automatically a theological dispute and must not be hidden simply to make a task easier to grade.

## Required authoring rule

If a mission depends on wording for which major modern Bible editions disclose a meaningful textual variant, the author must:

1. identify the affected passage;
2. record the variant in the mission source-audit notes;
3. avoid grading as universally identical wording what is not identical across the relevant textual traditions;
4. accept translation-equivalent answers when the underlying proposition remains adequate;
5. avoid penalizing a player merely for using a responsible translation that footnotes or represents the variant differently;
6. separate the fact of textual variation from any doctrinal conclusion drawn from it;
7. route doctrinal conclusions, if later discussed, through the normal I1/D1 transparency model.

## Internal adjunct label

Use `TX1` as an adjunct source note when a direct-scripture task is affected by a meaningful textual-transmission issue.

`TX1` does **not** replace T1/T2/C1/I1/D1. Example: a claim may be `T1 + TX1` when directly present in the textual form being used but subject to a disclosed manuscript variant.

## Player-facing behavior

The game should use plain language such as:

> Some manuscripts/translations present this wording differently. The difference is relevant to the wording of the task, so both responsible forms are recognized here.

The player should be able to inspect the note but should not be forced into a technical textual-criticism lesson unless the mission explicitly teaches that skill.

## Prohibited behavior

- claiming all manuscripts are identical when they are not;
- declaring a responsible translation «wrong» merely because it follows another textual decision;
- using a textual variant as automatic proof of a theological position;
- hiding the variant while requiring exact wording affected by it;
- making the player guess which translation the author had in mind.

## First canonical application

`LN-02 — За столом` applies this policy to Luke 22:19b–20 and notes related covenant-wording variation in Matthew 26:28 / Mark 14:24.
